# Persona D：行业观察者（T4 轻量版）

> 目标：不做主动投放前提下，确保关键观察者可以“有机看到”并愿意引用我们的内容。

## D 层定义（是谁）

D 层受众是“不会直接付费或立即加入，但会影响行业认知扩散的人群”，包括：

- 行业记者与科技媒体编辑
- 研究员、分析师、投资机构研究岗
- 垂直社区组织者、KOL、播客主持人
- 高活跃评论者与二次传播节点

他们核心特征是：关注“可引用观点 + 可验证证据 + 可传播表达”。

## 为什么重要

- 认知放大：D 层会决定哪些观点被二次传播，影响我们的行业心智占位。
- 可信背书：被研究/媒体引用的内容，会反向增强 A/B/C 层对我们的信任。
- 选题校准：D 层对“新议题/争议议题”的反馈，能帮助我们提前修正叙事角度。
- 外部信号：D 层关注点变化可作为栏目选题雷达，辅助“5 signal”栏目更新。

## 如何让他们“有机”遇到我们的内容（不做主动投放）

- 内容结构：
  - 每篇保留可引用的“结论句 + 证据句 + 边界句”三段结构；
  - 关键数据点标注来源，减少二次引用摩擦。
- 发布形态：
  - 长文保留 1 段 100-150 字摘要版本，便于媒体/研究者快速采样；
  - 固定输出“观点图表/清单”，提高被截图与转引概率。
- 渠道路径：
  - 公众号长文沉淀观点；
  - 小红书/抖音发布结构化切片，引流到原文；
  - 公开资料页保持可检索（标题关键词、统一标签、稳定链接）。
- 话题策略：
  - 优先写“有争议但可证据化”的议题，不写纯口号；
  - 对热点不抢速度，抢“可验证框架 + 复盘价值”。

## D 层内容完成度自检（轻量）

- 是否有一句可单独引用的判断？
- 是否给出最少 1 个数据或案例证据？
- 是否写清前提与不适用边界？
- 是否有一张可转述的图/表/清单？
