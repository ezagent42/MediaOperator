# 术语表 v0.1（T7）

> 用途：统一写作和审校语言，避免同一术语在不同栏目里含义漂移。

| 术语 | 定义 | 使用场景 | 使用注意 | 英文对应 |
|---|---|---|---|---|
| AI-native 组织 | 以 AI 为核心能力节点，围绕信息流与协作流重构流程的组织形态 | 对外方法论总述、长文开篇 | 不要写成“全自动组织”或“无人组织” | AI-native organization |
| 协作拓扑 | 人与 AI、角色与角色之间的协作关系结构 | 流程拆解、组织设计类内容 | 避免当作组织架构同义词 | collaboration topology |
| 信息网络中心 | AI 在组织中承担的信息处理与路由中枢角色 | 组织理念、机制设计解释 | 对外少用抽象说法，需配流程例子 | information-network center |
| DRI | 对阶段目标和结果负责的人 | 拆题栏目、项目复盘 | 对外优先写“阶段结果负责人” | Directly Responsible Individual |
| Player-Coach | 同时承担执行与协同育人职责的角色 | 团队协作、复盘机制 | 不直接等同传统中层管理 | Player-Coach |
| IC | 对某层关键能力深耕并交付结果的贡献者 | 岗位分工、能力模型 | 不是“只执行不负责” | Individual Contributor |
| agent workflow | 由多个 agent 与人工节点组成的任务编排流程 | 工具拆解、流程说明 | 必须写清输入输出和验收口径 | agent workflow |
| context engineering | 对任务上下文、约束、历史记忆的结构化管理 | 提示词/流程优化类内容 | 不简化成“写 prompt 技巧” | context engineering |
| 原创增量 | 在信息整理之外新增的判断、框架、对比或案例 | 审校标准、发布前检查 | 仅翻译/摘录不算原创增量 | original added value |
| signal | 可用于判断趋势变化或行动优先级的外部信号 | 周度 signal 栏目、选题会 | 需注明来源和时间窗口 | signal |
| 阵地 | 承载长期内容心智的主要发布渠道 | 渠道策略、排期讨论 | 不等同“所有分发平台” | primary channel |

## 审校口径（速查）

- 对外文稿里，术语首次出现时优先写“对外表达”，括号补术语英文。
- 同一篇中若出现 `AI-native`、`DRI`、`IC`，需至少配 1 个具体场景示例。
- 每周审校时检查：是否出现“术语堆砌但无执行步骤”的段落。
