### 1.3 人设与渠道匹配总结

-   **C端受众（潜在员工/追随者）**：偏爱生活化和趣味化内容。小红书、抖音、TikTok 是首选渠道；打造“AI 生活方式”形象。
-   **B端受众（客户/合作方/生态建设者）**：需要专业性和可信度。微信公众号、Medium、Reddit 的技术社区更适合。强调技术能力、案例分析和商业价值。
-   **综合指标**：通过 AI 建立一个 **跨平台监控系统**，聚合上述指标（互动率、完播率、粉丝增长、情感分析、转化行为）。建立自动仪表盘，实时反馈内容效果，为后续选题提供数据支撑。

## 3. 内容生产策略

### 3.1 保底策略（基础搬运）

1.  **海内外热门帖子/热榜监控**：
    1.  使用MCP工具自动抓取每日的与AI相关的抖音热榜、小红书热搜、TikTok Trending、Reddit 热门贴、行业新闻站点。
2.  **自动化中英双向翻译流转**：
    1.  通过高质量机器翻译模型（DeepL、Google Translate API 或使用自建的开源 NMT 模型）将抓取内容进行中英互译，并使用 AI 校正语法。
    2.  对关键术语进行词典维护，确保品牌与技术名称统一；翻译过程可用 LLM 进行润色与简化。
3.  **初步内容摘要**：
    1.  采用大型语言模型对原始文本进行摘要，提炼出核心观点、数据和洞察。
    2.  自动生成摘要后，由内部 AI 审查机制（如基于提示的置信度检测）筛查信息正确性。

### 3.2 升级策略（聚合后再输出）

1.  **热门选题聚合**：
    1.  利用 AI 整合监控到的热点，形成选题列表，标注热度指数、相关渠道和受众匹配度。
2.  **AI 智能大纲生成**：
    1.  通过 LLM 根据选题列表自动生成文章/视频脚本大纲，包括标题、章节结构、核心观点与必要的数据引用。
    2.  大纲生成时引用可靠数据来源，并根据不同渠道的表现形式调整结构（如 TikTok 短视频采用三幕结构，Medium 长文采用引言-主体-结论）。
3.  **人工审校**：
    1.  人工对大纲进行审校，确保与品牌语言风格、事实准确性和合规性一致。
4.  **AI 多模态内容生成**：
    1.  **文本生成**：调用 GPT-4、Gemini 等大语言模型完成文章、脚本与文案生成，并根据不同平台预设对应提示模板，控制内容语气、表达风格与篇幅长度。
    2.  **图像生成**：把通过 AI 收集的图片存在一个文件夹中以供随时筛选；还可以通过 Midjourney、GPT Image 2、Nano Banana、Stable Diffusion 生成符合视觉风格的配图。
    3.  **视频生成**：可使用 Seedance 2.0 等视频生成模型，将脚本、配音与数字人形象自动合成为视频内容；同时针对不同平台的内容形态预设提示模板，并按抖音、TikTok 等渠道的规格导出适配格式。
5.  **内容审核与发布**：
    1.  AI 检测内容安全性（敏感词、合规问题），生成审核报告。
    2.  通过 Agent 工具定时发布到各渠道。自动生成标题、标签和话题标签。
